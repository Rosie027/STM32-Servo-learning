# STM32F103 云台控制器：MPU6050 + 舵机 PID 丝滑控制

> 基于 STM32F103 的二维云台项目，涵盖 **PWM 舵机驱动、I2C/DMA 传感器读取、互补滤波姿态解算、PID 闭环控制**，并记录了完整的中断优先级、硬件最小系统与调试踩坑经验。  
> 适合作为 **STM32 外设基础综合实战** 的学习参考。

---

## 📖 项目简介

本项目使用 STM32F103C8T6 作为主控，通过 MPU6050 获取姿态数据，经互补滤波融合后，使用 PID 算法控制两个 SG90 舵机，实现云台的俯仰（Pitch）和横滚（Roll）角度闭环控制。  
代码采用标准库开发，模块化清晰，包含：

- 定时器 PWM 输出（50Hz，0.5ms~2.5ms 脉宽）
- 硬件 I2C2 + DMA1_Channel5 读取 MPU6050 加速度/陀螺仪数据
- 一阶互补滤波姿态解算
- 位置式 PID 控制器（支持 P、I、D 独立调参）
- 串口 CSV 格式调参输出（XCOM 上位机）
- 中断优先级规划与 ISR 极简原则

---

## ✨ 功能特性

| 模块 | 说明 |
| :--- | :--- |
| **舵机控制** | TIM 输出 50Hz PWM，CCR 映射 0°~180° 对应 0.5ms~2.5ms |
| **姿态读取** | MPU6050 六轴数据，I2C2 硬件接口，DMA 搬运 6 字节加速度数据 |
| **姿态融合** | 一阶互补滤波，融合加速度计（静态准）与陀螺仪（动态快） |
| **PID 控制** | 位置式 PID，输出目标角度，限幅 0~180°，支持调参 |
| **调试输出** | USART1 每 100ms 发送 CSV 格式：`pitch, roll, s1, s2, tick, err` |
| **异常保护** | I2C 读取全 0/全 -1 检测，连续失败自动复位 MPU6050 |

---

## 🧰 硬件平台

- **MCU**：STM32F103C8T6（72MHz，8MHz 晶振 + PLL 9 倍频）
- **传感器**：MPU6050（I2C 地址 `0x68`，AD0 接地）
- **执行器**：SG90 舵机 × 2（俯仰、横滚）
- **调试工具**：USB 转 TTL + XCOM 串口助手
- **电源**：3.3V 稳压，舵机独立 5V 供电（共地）

### 关键引脚分配

| 功能 | 引脚 | 外设 |
| :--- | :--- | :--- |
| MPU6050 SCL | PB10 | I2C2_SCL |
| MPU6050 SDA | PB11 | I2C2_SDA |
| 舵机 Pitch | PA8 | TIM1_CH1 |
| 舵机 Roll | PA9 | TIM1_CH2 |
| 串口 TX | PA9 | USART1_TX |
| 串口 RX | PA10 | USART1_RX |

> 注：舵机与串口引脚不冲突，实际项目可根据资源调整。

## 🏗️ 软件架构

```
├── Core
│   ├── main.c                 # 主循环，调度 control_tick
│   ├── stm32f10x_it.c         # 中断服务函数（TIM、DMA、USART）
│   └── ...
├── Hardware
│   ├── PWM.c / PWM.h          # 定时器 PWM 初始化与 CCR 设置
│   ├── I2C2.c / I2C2.h        # 硬件 I2C2 初始化与读写
│   ├── MPU6050.c / MPU6050.h  # 传感器初始化、数据读取
│   └── DMA_I2C2.c / .h        # DMA1_Channel5 配置与启动
├── Algorithm
│   ├── Attitude.c / .h        # 互补滤波姿态解算
│   └── PID.c / PID.h          # PID 控制器
└── App
    ├── Control.c / .h         # 控制节拍，舵机映射
    └── Serial.c / .h          # printf 重定向与 CSV 输出
```
